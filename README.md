# Plantagotchi (mimi)

An interactive, emotional plant companion made for my mom! This project monitors a plant's health and communicates its needs through expressions, colors, and sounds.

## How it Works
- **Brain:** ESP32-C3 SuperMini controls the logic loop.
- **Sensors:** Capacitive Soil Moisture Sensor v1.2 monitors water levels, and a DHT11 sensor tracks ambient temperature/humidity.
- **Outputs:** A 3.5-inch TFT LCD displays dynamic emotional faces, a WS2812B RGB LED strip changes color (e.g., turning blue when thirsty), and a DFPlayer Mini + Loudspeaker plays custom audio alerts.
